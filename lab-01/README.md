## 2. Покрокове виконання завдань

### Крок 1. Перевірка середовища
```bash
$ bash --version
GNU bash, version 5.2.15(1)-release (x86_64-pc-linux-gnu)
$ pwd
/home/eva/labs/operational-systems/lab-01
$ whoami
eva
```
* **Оболонка:** GNU Bash, версія 5.2+.
* **Поточний робочий каталог:** `/home/eva/labs/operational-systems/lab-01`.
* **Користувач:** `eva`.

### Крок 2. Створення структури каталогів
```bash
mkdir -p data backup reports
ls -la
```
* Команда `ls -la` відображає:
  * `.` — посилання на поточний каталог;
  * `..` — посилання на батьківський каталог;
  * створені підкаталоги `data`, `backup`, `reports` із правами доступу за замовчуванням `drwxr-xr-x`.

### Крок 3. Маніпуляції з файлами
```bash
# 1. Створення файлу з текстом
echo "перший запис" > data/readings.txt

# 2. Копіювання файлу в папку backup
cp data/readings.txt backup/readings-copy.txt

# 3. Перейменування файлу в backup
mv backup/readings-copy.txt backup/readings-renamed.txt

# 4. Створення структурованого набору даних через Here-Document
cat > data/measurements.txt <<'EOF'
12.5 sensor-a
14.0 sensor-b
11.2 sensor-a
13.8 sensor-b
10.9 sensor-a
EOF
```

### Крок 4. Опрацювання конвеєрами та фільтрами

| Конвеєр | Результат | Призначення утиліт |
|---|---|---|
| `cat data/measurements.txt \| sort` | `10.9 sensor-a`<br>`11.2 sensor-a`<br>`12.5 sensor-a`<br>`13.8 sensor-b`<br>`14.0 sensor-b` | `sort` виконує лексикографічне або числове сортування рядків. |
| `cat data/measurements.txt \| grep sensor-a` | `12.5 sensor-a`<br>`11.2 sensor-a`<br>`10.9 sensor-a` | `grep` фільтрує та виводить лише ті рядки, що містять шуканий шаблон `sensor-a`. |
| `cat data/measurements.txt \| wc -l` | `5` | `wc -l` підраховує кількість символів нового рядка (загальну кількість рядків). |
| `cat data/measurements.txt \| cut -d' ' -f1 \| sort -n` | `10.9`<br>`11.2`<br>`12.5`<br>`13.8`<br>`14.0` | `cut -d' ' -f1` виділяє перше поле (розділювач пробіл); `sort -n` сортує як дійсні числа. |
| `cat data/measurements.txt \| cut -d' ' -f1 \| sort -n \| tail -1` | `14.0` | `tail -1` повертає останній рядок відсортованого потоку (максимальне значення). |
| `cat data/measurements.txt \| cut -d' ' -f2 \| sort \| uniq` | `sensor-a`<br>`sensor-b` | `cut -f2` бере назву сенсора; `uniq` після попереднього `sort` видаляє повтори, залишаючи унікальні ідентифікатори. |

Символ `|` (конвеєр / pipe) з'єднує стандартний вивід (`stdout`, дескриптор 1) лівої команди зі стандартним вводом (`stdin`, дескриптор 0) правої команди без використання проміжних тимчасових файлів на диску.

### Крок 5. Формування звіту та автоматизація
Згенеровано файл `reports/report.txt`, що містить відсортовані вимірювання та контрольне число `5`. Створено сценарій `setup.sh` із директивою `set -euo pipefail`.

## 3. Відповіді на питання для захисту

1. **Що виводить команда `pwd`?**
   Команда `pwd` (print working directory) виводить абсолютний шлях до поточного робочого каталогу користувача від кореня файлової системи `/`.

2. **Чим відрізняється `cp` від `mv`?**
   * `cp` (copy) створює дублікат вмісту файлу за новим шляхом (виділяється новий inode та блоки даних на носії); оригінальний файл залишається без змін.
   * `mv` (move) переміщує або перейменовує файл. У межах однієї файлової системи `mv` лише оновлює запис у каталозі, пов'язуючи нове ім'я з наявним `inode` без фактичного копіювання байтів даних, а старе посилання видаляє.

3. **Що робить `grep` у наведених конвеєрах?**
   `grep` здійснює пошук рядків за регулярним виразом або підрядком (`sensor-a`) у вхідному потоці даних. Ті рядки, які містять зазначений фрагмент, передаються далі у конвеєр, інші — ігноруються.

4. **Для чого у `setup.sh` використано `set -euo pipefail`?**
   Це так званий «bash strict mode» для підвищення безпеки та надійності скрипта:
   * `-e` (errexit) — негайно зупиняє виконання сценарію, якщо будь-яка команда повернула ненульовий код завершення.
   * `-u` (nounset) — спричиняє помилку та зупинку при зверненні до неініціалізованої змінної.
   * `-o pipefail` — повертає ненульовий код виходу конвеєра, якщо хоча б одна команда в ланцюжку завершилася з помилкою (за замовчуванням Bash враховує лише статус останньої команди).
